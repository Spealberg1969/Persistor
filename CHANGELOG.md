# Changelog

Notable changes for Persistor releases are documented here.

## [0.4.1] — исправление в разработке

Версия Android-приложения: `0.4.1` (`versionCode 5`); релиз пока не опубликован.

### Исправлено

- Автоматическая рамка больше не следует за каждым отдельным результатом детектора: предварительный кандидат показывается янтарным, а зелёный статус появляется только после трёх последовательных согласованных наблюдений. Небольшое дрожание сглаживается; одиночные скачки не заменяют рамку сразу.
- Автоматическая обрезка применяется только при достаточной уверенности и поддержке градиентом по всем четырём сторонам. Слабый кандидат не должен обрезать снимок; ручная рамка остаётся приоритетной.
- Добавлены regression tests для стабилизации, дрожания/скачков, пропусков кадров, confidence gate и конкурирующей внутренней печатной сетки.

## [0.4] — в разработке

Версия Android-приложения: `0.4` (`versionCode 4`); релиз пока не опубликован.

### Добавлено

- Режим сканирования до спуска затвора: профиль заранее выбирает поддерживаемое камерой разрешение, а preview ищет контрастные границы документа и показывает найденный четырёхугольник.
- Автоматическое выравнивание перспективы и обрезка документа после съёмки; если надёжные границы не обнаружены, весь кадр сохраняется без автоматического обрезания.
- Ручная подстройка всех четырёх углов рамки прямо в live preview, в том числе когда автоматика не нашла лист.
- Три профиля JPEG: «Экран» до 1000 px / 200 КБ, «Обычный» до 1600 px / 450 КБ и «Печать» до 2400 px / 1,2 МБ. После геометрической коррекции изображение уменьшается и выполняется бинарный поиск максимального JPEG quality под byte cap; если лимит недостижим на минимальном разрешении, приложение сохраняет лучший доступный вариант и сообщает об этом.
- Для PDF применяется обнаружение/ручная рамка, perspective correction и профильное ограничение разрешения страницы; target byte cap профиля JPEG к PDF не применяется, потому что сжатие PDF остаётся в отдельной настройке.

### Проверка разработки

- Локально проходят 51 unit-тест, включая синтетическую перспективную страницу, ручное сопоставление координат viewport/source и подбор разрешения/качества.
- Android CV dependency не добавлена; границы ищутся облегченным линийным детектором, а warp выполняет Android `Matrix`.

## [0.3] — 2026-11-13

Первый опубликованный релиз Persistor. Версия Android-приложения: `0.3` (`versionCode 3`).

### Добавлено

- Съёмка документов в JPEG и PDF: отдельные папки назначения, одностраничные снимки и многостраничные PDF-сессии.
- Просмотр JPEG и PDF на весь экран, перелистывание файлов свайпом и стрелками, навигация по страницам PDF.
- Сжатие PDF с подбором качества JPEG по целевому SSIM; доступны бегунок и пресеты. Страницы рендерятся с ограничением до 200 dpi / 4 Мп, а исходный PDF сохраняется, если оптимизированный файл не становится меньше.
- Настраиваемый штамп даты/времени и имени на снимке: положение и размер текста. Подложка убрана, белый текст получил тонкую тёмную обводку.
- Ручная фиксация ориентации камеры и автоматическая фиксация после двух секунд стабильного положения, в том числе при запуске камеры в портретном режиме.
- Выбор для архива JPEG, PDF или обеих категорий. Имена папок и архивов содержат дату и категории (`_jpeg`, `_pdf`, `_jpeg_pdf`).

### Улучшено и исправлено

- Кнопка запуска камеры на главном экране увеличена с 56 до 84 dp (в 1,5 раза); кнопку спуска затвора это изменение не затрагивает.
- Навигация между файлами в полноэкранном просмотре заменена компактными стрелками; свайпы сохранены.
- Проверка ZIP включает чтение записей и проверку CRC32; при включённой пользователем настройке исходные файлы удаляются только после успешной проверки архива и только если они вошли в обработку.
- Восстановлена корректная фиксация портретной ориентации камеры при первом открытии.

### Форматы и репозиторий

- Поддерживаются Android JPEG, JPEGli, MozJPEG, WebP, JPEG XL, HEIF/HEIC и AVIF с учётом ограничений кодеков устройства.
- Удалена экспериментальная поддержка TIFF CCITT и JBIG2.
- Добавлены Android CI и unit-тесты; Actions закреплены по SHA, настроен Dependabot и ведётся манифест сторонних компонентов. Код приложения распространяется по MIT License.

### Проверка и распространение

- 42 unit-теста прошли; GitHub Actions Android CI завершился успешно.
- Установочный APK этого релиза подписан debug-ключом; для production-публикации нужна отдельная release-подпись.
