# Persistor

Android-приложение, которое превращает папку с фотографиями документов в один небольшой ZIP-архив, готовый к отправке по почте.

Проект сделан для личной рабочей задачи: за день снимается много документов, а архив из оригинальных фото получается больше 18 МБ и не уходит через Gmail. Persistor сжимает фото до минимально возможного размера при сохранении читаемости текста, складывает их в папку с текущей датой, пакует в ZIP и, если нужно, открывает Gmail с готовым письмом.

## Возможности

- **Выбор папок.** Одна или несколько исходных папок с фото, отдельные папки для сжатых файлов и для ZIP. Выбор запоминается между запусками.
- **Выделение.** Сетка миниатюр: отметить одно фото, несколько или все сразу.
- **Умное сжатие.** Для каждого фото подбирается минимальное JPEG-качество, при котором сходство с оригиналом (SSIM) не падает ниже заданной цели. Разрешение снимка не меняется.
- **Папка и архив с датой.** Результаты попадают в папку `ГГГГ-ММ-ДД`, из неё делается `ГГГГ-ММ-ДД.zip`. При повторном запуске в тот же день к имени добавляется `_2`, `_3` и так далее, старые файлы не перезаписываются.
- **Безопасная очистка.** Архив проверяется (число файлов и их размеры), и только после этого удаляются временная папка и, по желанию, исходные фото.
- **Фоновая обработка.** Работает как foreground-сервис с уведомлением о прогрессе, можно свернуть приложение или заблокировать экран.
- **Отправка в Gmail.** Список получателей с галочками, шаблон темы письма. Gmail открывается с уже заполненными адресатами, темой и вложением.
- **Быстрый режим.** По желанию: при запуске приложение через 5 секунд (с возможностью отмены) обрабатывает все фото.
- **Статистика.** История архивов: дата и время, размер, количество фото, адресаты, момент передачи в Gmail.

## Как это работает

1. Приложение читает изображения из выбранных исходных папок через Storage Access Framework.
2. Для каждого снимка:
   - декодирование и применение EXIF-поворота к пикселям (в результат EXIF не копируется, поэтому поворот «запекается»);
   - бинарный поиск качества JPEG в диапазоне от 40 до 95 (не более 8 итераций): кодирование, декодирование, сравнение с оригиналом по SSIM;
   - выбирается наименьшее качество, при котором SSIM не ниже цели (по умолчанию 0,95);
   - если цель недостижима даже на качестве 95, используется 95 и в итоге показывается предупреждение;
   - если исходный JPEG уже меньше пережатого, копируется без изменений.
3. Результаты записываются в папку с датой внутри папки «Сжатые файлы».
4. Из этой папки создаётся ZIP (без дополнительного сжатия, JPEG всё равно не сжимается) в папке для архивов.
5. Архив проверяется. Если проверка не прошла, ничего не удаляется, а испорченный архив стирается.
6. После успешной проверки удаляются временная папка и (если включено) исходные фото.
7. Показывается итог: размер архива и предупреждение, если он больше 17 МБ (с запасом под лимит Gmail в 25 МБ, учитывая кодирование вложений).
8. Копия архива кладётся в кэш приложения и передаётся в Gmail через FileProvider.

### Про SSIM

Используется упрощённый SSIM по яркости: окна 8×8 без перекрытия, снимок читается полосами, чтобы не расходовать память. Значения близки к «настоящему» SSIM, но не совпадают с другими программами. Нижняя граница качества (40) защищает от нечитаемого мелкого текста: на документах с большим белым фоном SSIM «прощает» ухудшение букв.

## Настройки

| Настройка | По умолчанию |
|---|---|
| Целевой SSIM (ползунок 0,90–0,99) | 0,95 |
| Удалять папку со сжатыми файлами после архивации | включено |
| Удалять исходные фото после успешной архивации | выключено (с подтверждением) |
| Быстрый режим | выключено |
| Открывать Gmail после архивации | включено |
| Тема письма (`{date}` заменяется на дату архива) | `Документы {date}` |

## Отправка по почте и статистика

Android не позволяет приложениям отправлять письма втихую, поэтому Persistor открывает Gmail с заполненным письмом, а нажать «Отправить» нужно самому. Gmail не сообщает приложению, было ли письмо отправлено, поэтому в статистике фиксируется момент «Gmail открыт», а не факт отправки. Надёжное подтверждение смотрите в папке «Отправленные» в Gmail.

Кнопка «Отправить в Gmail» есть в окне результата и в уведомлении по окончании обработки. Все пути проходят через приложение и попадают в статистику.

## Технологии

- Kotlin 2.0, Jetpack Compose (Material 3), Coil для миниатюр
- Storage Access Framework и `DocumentFile`, без разрешений на доступ ко всем файлам
- DataStore Preferences для настроек и истории
- `ExifInterface` для поворота снимков
- Foreground-сервис (`dataSync`), `FileProvider`, уведомления
- Gradle 8.9, Android Gradle Plugin 8.6, JDK 17, compileSdk 34, minSdk 24

## Структура проекта

```
app/src/main/java/com/persistor/
  MainActivity.kt        интерфейс (Compose): папки, сетка, настройки, статистика
  MainViewModel.kt       состояние экрана, запуск обработки, отправка
  Processor.kt           конвейер: сжатие, папка с датой, ZIP, проверка, очистка
  Ssim.kt                упрощённый SSIM по яркости
  ProcessingService.kt   фоновый сервис, уведомления, копия архива для Gmail
  ProcessingState.kt     общее состояние и модели данных
  FolderStore.kt         DataStore: папки, настройки, получатели, история
  ImageRepository.kt     список изображений из выбранных папок
  Mailer.kt              запуск Gmail с вложением
  Util.kt                вспомогательные функции
```

## Сборка через GitHub Actions

Сборка не требует компьютера: APK собирается в облаке GitHub.

В репозитории лежат два файла:

- `project.zip` — весь проект Android (Gradle, манифест, исходники);
- `.github/workflows/build.yml` — сценарий сборки.

При каждом коммите workflow распаковывает `project.zip`, собирает debug-APK командой `gradle assembleDebug` и публикует его как артефакт **Persistor-apk**.

**Получить APK:** вкладка **Actions** → последний запуск → раздел **Artifacts** → `Persistor-apk` → распаковать скачанный ZIP → установить `app-debug.apk`.

**Обновить приложение:** загрузить новый `project.zip` с тем же именем (**Add file → Upload files**), дождаться зелёной галочки, скачать и установить APK поверх старой версии. Настройки сохраняются.

> APK подписан отладочным ключом. Для личного использования этого достаточно.

## Права и конфиденциальность

- **Уведомления** — чтобы видеть прогресс фоновой обработки.
- **Foreground-сервис и WakeLock** — чтобы обработка не прерывалась при выключенном экране.
- Доступ к папкам выдаётся через системный выбор папки и действует только на выбранные папки.
- В приложении нет разрешения на доступ в интернет: фото и архивы никуда не передаются сами. Отправка происходит только через Gmail, когда вы нажимаете «Отправить».

## Ограничения

- Прозрачные области PNG при конвертации в JPEG становятся чёрными.
- Для очень больших снимков может не хватить памяти, в этом случае показывается ошибка, исходные фото не затрагиваются.
- Быстрый режим обрабатывает все фото в исходных папках. Если не включено удаление исходников, при следующем запуске они будут обработаны повторно и дадут архив `_2`.
- Приложение не пытается определить рамку документа и не выравнивает перспективу: оно занимается только сжатием и архивацией.
