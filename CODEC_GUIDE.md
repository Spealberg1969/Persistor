# Экспериментальные форматы изображений

В настройках обработки теперь доступны девять режимов: стандартный Android JPEG, JPEGli, MozJPEG, WebP, JPEG XL, HEIF/HEIC, AVIF, TIFF с CCITT Group 4 и JBIG2. В результирующей папке каждому режиму назначаются соответствующее расширение и MIME; архив ZIP продолжает проходить потоковую проверку размера и CRC для каждого файла.

## Как работает подбор качества

Для JPEG, JPEGli, MozJPEG, WebP, JPEG XL, HEIF и AVIF Persistor ищет минимальное качество кодека, при котором декодированное изображение достигает выбранной цели SSIM. JPEG XL декодируется для проверки через библиотеку JXL, остальные форматы — через Android. Если устройство не может выполнить выбранный формат или прочитать его результат для SSIM, обработка завершится с ошибкой; молчаливого переключения на JPEG нет.

HEIF/HEIC доступен начиная с Android 10 (API 29), AVIF — начиная с Android 14 (API 34). В обоих случаях нужны подходящие системный кодек и возможности устройства. WebP кодируется платформенным Android API. JPEGli и MozJPEG собираются в отдельные native-библиотеки; JPEG XL использует библиотеку `io.github.awxkee:jxl-coder:2.2.0`.

## Документные режимы

TIFF G4 и JBIG2 преобразуют цветное фото в однобитное чёрно-белое изображение с фиксированным порогом яркости 160. Эти режимы предназначены для сканов текста, а не фотографий. Информация о цвете и полутонах теряется, поэтому поиск SSIM и JPEG-параметра качества не применяется. Для JBIG2 используется lossless generic-region encoding; потери возникают только на этапе бинаризации. Чтобы не потерять цветной оригинал, приложение не удаляет исходные фото после этих двух режимов, даже если переключатель удаления включён.

Формат JBIG2 имеет расширение `.jb2` и MIME `application/octet-stream` для совместимого создания файла в SAF. Поддержка JBIG2 в обычных галереях ограничена; это формат для документных workflow. TIFF G4 создаёт одностраничный монохромный TIFF.

## Сборка и тесты

Нативные библиотеки собираются Android NDK `27.2.12479018` и CMake `3.22.1` для ABI `arm64-v8a`, `armeabi-v7a` и `x86_64`. Версии Gradle и Kotlin зафиксированы wrapper и root build-файлом.

```bash
./gradlew testDebugUnitTest
./gradlew assembleDebug
```

Unit-тесты проверяют потоковую CRC-верификацию ZIP и метаданные всех режимов сжатия. `assembleDebug` выполняет Android/Kotlin/Compose и NDK cross-build, включая упаковку библиотек. Для системных HEIF/AVIF-кодеков наличие самого собранного APK не заменяет тест на конкретной модели телефона.

## Сторонние исходники

Исходники JPEGli, MozJPEG, libtiff, Leptonica и jbig2enc включены в `app/src/main/cpp` вместе с upstream-лицензиями. Локальные изменения путей заголовков и CMake помечены в соответствующих файлах. JPEG XL Android coder поставляется из Maven Central; notices для native и AndroidX-компонентов находятся в `app/src/main/assets/THIRD_PARTY_NOTICES.txt`.
